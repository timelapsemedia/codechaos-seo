# MusicBrainz: Releases mit einem Klick eintragen

Stand 05.10.2026. Auf MusicBrainz steht bei Code Chaos noch kein einziges Release. So gehst du vor:
1. Bei https://musicbrainz.org einloggen.
2. Unten auf einen Link klicken. Das Release-Formular öffnet sich mit Titel, Artist, Datum, Label, Format, Tracklist und Links.
3. Durch die Reiter klicken. Beim Label „Abstract Sound Design“ einmalig „Neues Label anlegen“ wählen, ab dem zweiten Release ist es dann auswählbar.
4. Unten auf **Enter edit** klicken. Fertig.

## Alle anderen Releases: Bandcamp-Importer (ein Klick pro Release)
Für die übrigen Alben und EPs kann ich die Tracklisten nicht abrufen, weil Bandcamp meine Anfragen blockiert. In deinem Browser klappt es mit dem offiziellen Community-Skript von MusicBrainz:
1. Die Browser-Erweiterung **Tampermonkey** installieren (Chrome, Firefox oder Edge).
2. Das Skript öffnen und auf „Installieren“ klicken: https://raw.githubusercontent.com/murdos/musicbrainz-userscripts/master/bandcamp_importer.user.js
3. Eine Release-Seite auf codechaos.bandcamp.com öffnen. Dort steht jetzt ein Button **„Import into MB“**. Klicken, prüfen, „Enter edit“.

Betrifft: Insomnia, Heart & Mind, Parallax Prison – Schism of Self, A Tiny Piece Of Paper, Filaments & Voids, Paradigma, Fun With Noises, Oblivion, The Grudge, The Slaughterhouse, Interstellar, The Twilight Zone, Det Stora Oväsendet, Roadside Butchery, Live at Arnsteinhöhle (Release-Typ zusätzlich „Live“), Ghosts (Bootleg) und Schattenraum (Compilation).

Die Links öffnen nur das Formular von MusicBrainz, angelegt wird erst etwas, wenn du auf „Enter edit“ klickst. Falls ein Link nach dem Login ein leeres Formular zeigt: `musicbrainz-import.html` im Browser öffnen. Dort öffnet jeder Button dasselbe Formular, nur per POST-Anfrage.
