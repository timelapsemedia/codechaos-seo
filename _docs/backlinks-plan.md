# Link-Plan für Platz 1 (psycore, darkpsy, hitech psy, psytrance mastering)

Google vergibt Platz 1 vor allem an Seiten, auf die andere Seiten verlinken. Die Inhalte sind jetzt da. Was fehlt, sind Links von außen auf die **Unterseiten**, nicht nur auf die Startseite. Reihenfolge nach Wirkung und Aufwand.

- polished.media verlinkt im Footer (EN + DE) auf `/en/mastering/` bzw. `/mastering/`

Auf abstract-sound-design.de bei Code Chaos bzw. auf einer „Genres“-Seite:

## 5. Datenbanken (Entität für Google & KI)
Discogs, MusicBrainz, Wikidata: Vorlage in `_docs/entitaeten-wikidata-discogs-musicbrainz.md`. Jeweils `https://codechaos-official.de/` als offizielle Website eintragen.

## 6. Community (nur echte Antworten, kein Spam)
Reddit (r/psytrance, r/edmproduction), Psytrance-Facebook-Gruppen, Discord-Server: Wenn jemand fragt „Was ist Psycore?“, „Hitech vs Psycore?“, „Darkpsy BPM?“, kurz antworten und den Guide als Quelle verlinken. 3–5 gute Antworten pro Monat reichen.

## 7. Kooperationen
- Interviews/Features bei Psytrance-Blogs, Podcasts, Radioshows: in der Artist-Info immer `codechaos-official.de` angeben.
- Labels, für die du gemastert hast: Credit „Mastered by Code Chaos“ mit Link auf `/mastering/`.
- Festival-/Party-Lineups und Pressetexte: Website-Link statt nur Instagram.
