Code Chaos Audio

Audio-Plugins von Code Chaos Audio

Code Chaos Audio ist die Plugin-Reihe von Code Chaos (Tim Borchert, Hamburg): VST3-Plugins für Hitech, Psycore und Darkpsy und die Code Chaos Black Metal Suite. Alle Plugins gibt es auf Gumroad als Sofort-Download, zu jedem Bezahl-Plugin eine kostenlose Demo (vollständiges Plugin mit einem kurzen Rauschen alle 45 Sekunden).

Für Hitech, Psycore und Darkpsy

Gebaut für schnelle, dichte Psytrance-Produktionen: Sättigung, Glitch, FM-Sounds und Kontrolle über Kick und Bass.

Crucible

3-Band-Sättigung: Hard Clip, Wavefolder, Tube, Diode oder Tape pro Band, bis 8x Oversampling.
