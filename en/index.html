About Code Chaos

Ten years at the extreme edge of psytrance

Code Chaos is a hitech psytrance, psycore and darkpsy producer from Hamburg, Germany, and the studio project of Tim Borchert. Active since 2016, Code Chaos has released 24+ records between 180 and 300 BPM on labels including Abstract Sound Design (co-founded in 2021), TATEWARI Records (Mexico) and Soma Ritual Records (India).

Code Chaos does not make music for the daylight. Somewhere between a psytrance floor at 4 a.m. and a crypt that smells of candle wax, these tracks tick like a heart about to break. Liquid FM lines crawl through the skull, the bass never stops rolling, and voices tell stories you should not hear alone.

Code Chaos calls it New Psychedelic Death Art. With "Uhrwerk aus Blut" the project opens up to story, voice and image. Today Code Chaos is a studio-only project without bookings. Earlier there were live sets, for example at Abstract Ritual Hamburg (2023) and Lost Signal Festival (2026).

Alongside the music, Code Chaos offers mastering for psytrance, hitech and psycore as Code Chaos Mastering and builds plugins as Code Chaos Audio, starting with Crucible.

FAQ

Is "Uhrwerk aus Blut" out yet?

Yes. The single "Uhrwerk aus Blut" (Clockwork of Blood) was released on 30 October 2026 on Abstract Sound Design: listen now. The next release is Wiedergänger Vol. I · Was nicht ruhen will on 4 December 2026.

Who is behind Code Chaos?

Code Chaos is the studio project of Tim Borchert, a producer from Hamburg, Germany, active since 2016. He co-founded the label Abstract Sound Design in 2021, offers mastering for psytrance, hitech and psycore as Code Chaos Mastering and develops audio plugins as Code Chaos Audio, starting with Crucible.

Can I book Code Chaos for a live show or DJ set?

No. Today Code Chaos is a studio-only project without bookings. Earlier there were live sets, for example at Abstract Ritual Hamburg (2023) and Lost Signal Festival (2026). You can work with Code Chaos through mastering, cover art and video services.

What is "New Psychedelic Death Art"?

New Psychedelic Death Art is Code Chaos' own name for the project's sound: hitech, psycore and darkpsy at 180–300 BPM, combined with gothic atmosphere, liquid FM lines, a bassline that never stops rolling and voices that tell stories. Music not made for the daylight, somewhere between a psytrance floor at 4 a.m. and a crypt that smells of candle wax. The first release of this era is the single Uhrwerk aus Blut.

What genres does Code Chaos produce?

Hitech psytrance, psycore and darkpsy, mostly between 180 and 300 BPM, plus experimental releases. Read the guides to psycore, hitech psytrance and darkpsy.

How much does mastering cost?

Single (stereo) €79, Stem Pro €129 per track (up to 6 stems), EP up to 5 tracks €349 (€69.80 per track), album up to 10 tracks €629 (€62.90 per track). All prices incl. 19% VAT, with audio audit and unlimited revisions.

What is Crucible?

Crucible is a 3-band harmonic saturation plugin (VST3 + standalone for Windows, €19) by Code Chaos Audio. Low, mid and high are saturated separately with hard clip, wavefolder, tube, diode or tape, with per-band drive, mix and gain and up to 8x oversampling.
