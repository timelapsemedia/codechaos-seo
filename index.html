Vorher/Nachher: Uhrwerk aus Blut

Zwei Ausschnitte von je 16 Takten (18 Sekunden) aus der Code-Chaos-Single „Uhrwerk aus Blut“ (210 BPM). Vorher ist der freigegebene Pre-Master, also der Mixdown vor dem Mastering. Nachher ist das veröffentlichte Master. Beide Fassungen sind pegelgleich auf −13 LUFS gebracht, damit du den Klang vergleichst und nicht die Lautstärke. Das veröffentlichte Master selbst liegt bei rund −9 LUFS.

Über Code Chaos

Ein neues Zeitalter

Code Chaos macht keine Musik für das Tageslicht. Irgendwo zwischen einem Psytrance-Floor um vier Uhr morgens und einer Gruft, die nach Kerzenwachs riecht, entstehen Tracks, die ticken wie ein Herz kurz vor dem Zerbrechen. Code Chaos nennt es New Psychedelic Death Art.

Code Chaos ist das Studioprojekt von Tim Borchert aus Hamburg, aktiv seit 2016. Über 24 Releases auf Labels wie Abstract Sound Design (2021 mitgegründet), TATEWARI Records (Mexiko) und Soma Ritual Records (Indien), zwischen 180 und 300 BPM. Dichtes Sounddesign, hypnotische Strukturen, unerbittlicher Drive.

Mit „Uhrwerk aus Blut“ öffnet sich das Projekt für Erzählung, Stimme und Bild. Heute ist Code Chaos ein reines Studioprojekt ohne Bookings. Früher gab es Live-Sets, unter anderem bei Abstract Ritual Hamburg (2023) und beim Lost Signal Festival (2026). Daneben entstehen das Plugin Crucible und Code Chaos Mastering, der Mastering-Service für elektronische Musik. Metal und Gothic mastert Tim unter Polished Media.
