Fragen zu Psycore & Hitech

PSYCORE · HITECH PSYTRANCE · DARKPSY · MASTERING

Was ist Psycore Musik? +

Psycore ist ein Subgenre des Psytrance das bei Tempos von 180 bis über 300 BPM operiert. Es kombiniert die hypnotischen Soundscapes des Dark Psytrance mit der Energie des Hardcore. Charakteristisch sind dichte atmosphärische Pads, experimentelles Klangdesign, minimale Sinuswellen-Percussion und ein statisch-meditatives Klangbild. Code Chaos ist einer der aktivsten Psycore Produzenten Deutschlands mit 24+ Releases im Psycore- und Hitech-Bereich. Mehr im Psycore Guide →

Was ist Hitech Psytrance (Hi-Tech)? +

Hitech Psytrance (auch Hi-Tech, Hitech Psy) ist ein Psytrance-Subgenre bei 170–230+ BPM mit futuristischem, alien-artigem Klangdesign. Der Begriff wurde von den russischen Künstlern Osom (Kindzadza & Psykovsky) geprägt. Hitech unterscheidet sich von Psycore durch seine dynamische, überraschungsreiche Struktur, es kann dunkel aber auch euphorisch sein. Code Chaos ist aktiver Hitech Psytrance Producer aus Deutschland. Mehr im Hitech Psytrance Guide →

Was ist Dark Psytrance / Darkpsy? +

Darkpsy (Dark Psy, Dark Psytrance) ist das dunkle Herzstück des Psytrance-Spektrums bei 150–200 BPM. Es entstand nach 2003 mit starkem Einfluss aus Deutschland und Russland. Charakteristisch sind Horror-Film-Samples, schwere Basslines, okkulte Ästhetik und eine Atmosphäre die Tod, Nacht und Transzendenz beschwört. Darkpsy ist die evolutionäre Basis für Hitech Psytrance und Psycore. Code Chaos produziert Darkpsy im Studio, unter anderem auf den Alben „Oblivion“ und „The Twilight Zone“ (2022). Mehr im Darkpsy Guide →

Was ist der Unterschied zwischen Psycore, Hitech und Darkpsy? +

Darkpsy (150–200 BPM) ist atmosphärisch, dunkel, okkulte, die Basis des schnellen Psytrance. Hitech Psytrance (170–230+ BPM) ist futuristisch, komplex und synthetisch, kann dunkel oder euphorisch sein. Psycore (180–300+ BPM) ist das Extremste: statisch-hypnotisch, minimal, meditativ-brutal. Alle drei sind verwandte Genres, Code Chaos produziert alle drei als reines Studioprojekt.

Welche BPM hat Psycore? Und Hitech Psytrance? +

Psycore BPM: 180 bis über 300 BPM, einzelne Tracks erreichen sogar 400 BPM. Psycore ist damit eines der schnellsten Musikgenres überhaupt. Hitech Psytrance BPM: 170 bis 230+ BPM. Darkpsy BPM: 150 bis 200 BPM. Code Chaos produziert in einem Bereich von 180 bis 300 BPM und bewegt sich damit im Kern aller drei Genres.

Was unterscheidet Psycore von Speedcore und Flashcore? +

Psycore unterscheidet sich von Speedcore und Flashcore durch seine psychedelischen Soundscapes und das Psytrance-Fundament. Während Speedcore und Flashcore rein rhythm-basiert und extrem aggressiv sind, bewahrt Psycore die hypnotischen, meditativen Qualitäten des Psytrance, bei ähnlichen oder noch höheren Tempos. Psycore überwindet die statischen Formen des Hardcore durch morphende Soundscapes und psychedelische Tiefe. Dark Ambient und Glitch sind starke Einflüsse.

Das nächste Release ist Wiedergänger Vol. I · Was nicht ruhen will am 4. Dezember 2026. Der Track erzählt in fünf Szenen von einem Herzen, das zu schnell schlägt, und eröffnet die dunklere, erzählende Gothic-Ära von Code Chaos.

Wer steckt hinter Code Chaos? +

Code Chaos ist das Studioprojekt des Hamburger Producers Tim Borchert, aktiv seit 2016. Er hat 2021 das Label Abstract Sound Design mitgegründet, bietet als Code Chaos Mastering Mastering für Psytrance, Hitech und Psycore an und entwickelt unter dem Namen Code Chaos Audio eigene Audio-Plugins wie Crucible.

Kann man Code Chaos live oder als DJ buchen? +

Nein. Code Chaos ist heute ein reines Studioprojekt ohne Bookings. Früher gab es Live-Sets, unter anderem bei Abstract Ritual Hamburg (2023) und beim Lost Signal Festival (2026). Wer mit Code Chaos arbeiten möchte, kann Mastering, Cover Art und Videos über das Anfrageformular buchen.

Was ist „New Psychedelic Death Art“? +

New Psychedelic Death Art ist die Eigenbezeichnung von Code Chaos für den eigenen Sound: Hitech, Psycore und Darkpsy bei 180–300 BPM, verbunden mit Gothic-Atmosphäre, flüssigen FM-Lines, einem ununterbrochen rollenden Bass und erzählenden Stimmen. Musik „nicht für das Tageslicht“, irgendwo zwischen einem Psytrance-Floor um vier Uhr morgens und einer Gruft, die nach Kerzenwachs riecht. Erstes Werk dieser Ära ist die Single „Uhrwerk aus Blut“.

Was ist Crucible von Code Chaos Audio? +

Crucible ist ein 3-Band Harmonic Saturation Plugin (VST3 + Standalone für Windows, 19 €). Low, Mid und High werden getrennt gesättigt, mit Hard Clip, Wavefolder, Tube, Diode oder Tape pro Band, Drive, Mix und Gain pro Band und bis zu 8x Oversampling. Gebaut für Psytrance, Hitech, Psycore und Darkpsy, funktioniert aber auf jeder Quelle. Alle Features · auf Gumroad kaufen.
